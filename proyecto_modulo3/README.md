# 📦 Gestión de Inventarios en Python

Un sistema eficiente, interactivo y modular para la gestión de productos en inventario desarrollado en Python. Este proyecto aplica buenas prácticas de programación, modularización de código (PEP 8), estructuras de datos fundamentales, control de excepciones y algoritmos recursivos.

---

## 🚀 Características Principales:

* 📝 **Operaciones CRUD:** Agregar, listar, buscar, modificar y eliminar productos.
* 🛡️ **Validación de Datos:** Control de excepciones (`try / except`) para evitar entradas no válidas o cierres inesperados.
* 🏷️ **Categorización:** Filtrado de categorías únicas utilizando conjuntos (`set`).
* 🔢 **Cálculo Recursivo:** Módulo para la resolución de factoriales mediante funciones recursivas.
* 📊 **Exportación CSV:** Generación automática de reportes de datos en formato `.csv`.

---

```text
├── main.py          # Menú principal y flujo del programa
